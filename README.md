
# PhishScope 🛡️

PhishScope is a lightweight Bash-based phishing detection and analysis tool.

## Features

- Domain entropy detection
- Suspicious keyword analysis
- Domain age intelligence
- SSL certificate inspection
- Redirect detection
- Webpage content scanning
- Risk scoring engine
- JSON output

## Installation

```bash
sudo apt install whois curl openssl bc -y
chmod +x phishscope.sh

Usage
./phishscope.sh https://example.com

Output
      Risk Score
      Risk Level
      Analysis Report
      JSON Result
